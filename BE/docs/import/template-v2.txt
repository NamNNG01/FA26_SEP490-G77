Q7. Explain why Java uses garbage collection and what trade-off it brings.
POINTS: 4
RUBRIC:
- Memory management | 2 | Explains that unreachable objects are reclaimed automatically
- Trade-off | 2 | Mentions pause time or runtime overhead
SAMPLE:
Java reclaims memory of objects that are no longer referenced, so developers
do not free memory manually. The cost is that collection runs at unpredictable
times and can cause pauses.
